# RAI/AIEC 評測工具介面

此專案提供一個以 HTML、CSS 與少量原生 JavaScript 製作的批改管理介面原型，對應客製化評測工具的 wireframe。

## 開發與預覽

1. 於專案根目錄啟動簡單的靜態伺服器，例如：
   ```bash
   python -m http.server 8080
   ```
2. 透過瀏覽器前往 `http://localhost:8080`，即可瀏覽互動式樣板。

## 功能亮點

- 具備考生列表、批改詳情與作答內容的雙欄佈局，貼近批改流程。
- 針對 AI 建議、老師評分與評分規準提供切換視圖，模擬批改情境。
- 包含批改紀錄時間軸、狀態徽章與篩選表單等 UI 元件，可作為視覺設計與前端實作的參考。
