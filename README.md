# 題庫健康水位監控儀表板

此專案提供一個可部署到 GitHub Pages 的純前端儀表板原型，用來監控 AIEC 題庫在「資安、公平、隱私」三個評估面向下，各難易度的題數健康水位。

## 開發與預覽

1. 於專案根目錄啟動簡單的靜態伺服器，例如：
   ```bash
   python -m http.server 8080
   ```
2. 透過瀏覽器前往 `http://localhost:8080`，即可瀏覽互動式儀表板。

## 功能亮點

- 以「難、中偏難、中偏易、易」作為 X 軸，分別呈現資安、公平、隱私三個評估面向的題數長條圖。
- 每個長條圖依子指標切分顏色區塊，可快速判斷同一難易度中的題型組成。
- 每個難易度同時顯示兩條安全水位線：
  - 單張考卷配比安全線：依每張考卷總題數、評估面向比例、難易度比例與緩衝係數計算。
  - 下月專案需求安全線：依預估專案數量、每專案考卷份數與難易度比例計算。
- 可直接調整監控參數，前端會即時重算健康分數、缺題數與補題優先順序。
- 不依賴打包工具或後端服務，適合直接透過 GitHub Pages 預覽；未來可將 `script.js` 中的假資料替換為 API 回傳資料。
